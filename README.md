# Applied Data Science Capstone

This project explores SpaceX launch data to predict whether Falcon 9's first stage will land successfully. The analysis combines API data, web scraping, SQL queries, geospatial visualization, and machine learning.

## What this project covers
- Collecting and cleaning SpaceX launch data
- Scraping Falcon 9 launch records from public sources
- Exploring launch trends, site locations, and payload patterns
- Building an interactive dashboard for launch analysis
- Training and comparing classification models

## Key outcome
The final model identifies the best-performing classifier for first-stage landing prediction, helping estimate launch cost and mission risk more accurately.

## Repository contents
- Notebook files for data collection, cleaning, SQL analysis, visualization, and modeling
- `spacex_dash_app.py` for the Plotly Dash dashboard
- `spacex_launch_geo.csv` for launch site and geographic data
- `DS-Capstone-Coursera-Siddharth-Shanmugaraja.pdf` for the presentation summary
- `my_data1.db` for database work
